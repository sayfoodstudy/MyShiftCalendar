# 3교대 달력알람 v0.1-calendar

개인용 Android 네이티브 앱입니다. 1차 버전은 알람 기능을 제외하고 **3교대 달력 기능**을 먼저 구현합니다.

## 현재 포함 기능

- 주간 시작일 설정
- `주간 → 당직 → 비번` 반복 계산
- 토요일/일요일/한국 공휴일 + 주간 근무가 겹치면 `주휴` 자동 표시
- 수동 근무 변경
  - 자동 계산
  - 주간
  - 당직
  - 비번
  - 주휴
  - 사용자가 추가한 근무 종류
- 근무 종류 관리
  - 기본: 주간, 당직, 비번, 주휴
  - 사용자 근무 종류 추가 가능 예: 연차, 교육, 출장
  - 색상/짧은 표시/분류 저장
- 기간 일정 추가
  - 시작일~종료일
  - 색상 라인 표시
  - 같은 날짜에 여러 일정이 겹치면 라인이 쌓임
- 한국 공휴일 2026년~2035년 내장
- 인터넷/서버/로그인 필요 없음

## 아직 제외된 기능

- 알람 기능
- 반복 알람
- 3교대 조건 알람
- 공휴일 직접 수정
- 데이터 백업/복원
- 정식 release 서명 APK

## GitHub Actions로 APK 만들기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 모든 파일을 저장소 최상단에 업로드합니다.
3. `.github/workflows/build-apk.yml` 파일이 저장소에 있어야 합니다.
4. 저장소의 `Actions` 탭으로 이동합니다.
5. `Build Android APK` 워크플로가 실행되게 합니다.
   - 업로드 후 자동 실행되거나
   - `Run workflow` 버튼으로 수동 실행합니다.
6. 빌드 완료 후 `Artifacts`에서 `shift-calendar-alarm-debug-apk`를 다운로드합니다.
7. 압축을 풀면 `app-debug.apk`가 있습니다.
8. 삼성폰에 설치합니다.

## 숨김 폴더 주의

`.github` 폴더는 숨김 폴더라서 업로드할 때 빠질 수 있습니다.
빠지면 GitHub에서 직접 아래 파일을 만들어도 됩니다.

```text
.github/workflows/build-apk.yml
```

## 첫 실행

앱을 처음 실행하면 `주간 시작일`을 설정합니다.
이 날짜가 `주간`인 날이며, 이후 날짜는 자동으로 `주간 → 당직 → 비번` 순서로 계산됩니다.

## 규칙

1. 기본 순번은 주간/당직/비번만 사용합니다.
2. 주간이 토/일/공휴일과 겹치면 주휴로 표시합니다.
3. 주휴가 생겨도 다음날 근무 순번은 밀리지 않습니다.
4. 수동 근무 변경은 해당 날짜 하루에만 적용됩니다.
5. 수동 변경이 있으면 휴일 자동 주휴보다 우선합니다.
6. 추가 근무 종류는 자동 순번에 들어가지 않고, 수동 변경 선택지로만 사용됩니다.

## 테스트 추천

1. 첫 실행 후 주간 시작일 설정
2. 이번 달 달력에 주간/당직/비번 표시 확인
3. 토/일/공휴일에 주간이 걸린 날이 주휴로 바뀌는지 확인
4. 특정 날짜를 당직/비번/주휴로 수동 변경
5. 설정 → 근무 종류 관리 → 연차 같은 근무 추가
6. 날짜 클릭 → 추가 근무 종류로 변경
7. 기간 일정 추가 후 달력 라인 표시 확인

## 주의

현재 APK는 debug APK입니다. 나중에 진짜 장기 사용 버전으로 갈 때는 고정 서명키가 있는 release APK로 바꾸는 것이 좋습니다.
